# EzraTech Enterprise Infrastrucure Deployment

## Project overview:

This project demonstrates the design and deployment of a secure enterprise network infrastrucure for EzraTech, an IT consulting company with 50 employees.

The goal of this project is to simulate a real-world small business environment using Windows Server, Active Directory, pfSense firewall, and secure remote access technologies.

# Technologies used

-Windows Server 2022
-Windows 11 Enterprise
-Active Directory Domain Services
-DNS
-DHCP
-Group policy
-File Server
-PfSense Firewall
-OpenVPN
-VirtualBox

# Project Objectives

This infrasctrucure will provide:

-pfSense firewall acting as a network gateway
-windows server acting as the Domain Controller
-windows 11 client machine joined to the domain
