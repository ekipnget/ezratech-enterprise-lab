# Project Scenario

## Company profile

EzraTech is a techonology company with approximately 50 employees. The company requires a secure and centralized IT infrastrucure to support daily operations.

The company needs a reliable network environment that allows employees to securely access company resources, communicate internally and work remotely when needed.

# Business challenge

As a company grows managing individuals computers and user accounts locally becomes difficult. 

EzraTech requires an enterprise network solution that provides:

- Centralized access control
- secure access control
- Automated network configuration
- Internal name resolution
- Secure remote connectivity
- Centralized security policies


# Project Ojective

As the System Administrator, i have been assigned to design, configure, and document an enterprise infrasctrucure environment for EzraTech. 

The goal is to simulate a real-world small business network deployment using industry-standard technologies.

# Proposed solution

The infrastrucure will include:

## Identity Management

Windows server will be deployed as the Domain Controller to provide:

-Active Directory Domain Services (AD DS)
- User and Computer management
- Authentication
- Group Policy management

## Network Services

The environment will provide:

- DNS for internal name resolution
- Firewall protection
- Network Address Translation (NAT)
- VPN services

## Remote Access

OpenVPN will be configured to allow authorized employeed to securely access internal company resources remotely.

# Project Scope

This project will cover the deployment of:

- Windows server Domain Controller
- Active Directory
- DNS
- Group policy
- File Server
- PfSense Firewall
- OpenVPN Remote Access
- Windows 11 Domain Client

# Expected outcome:

At the completion of this project, EzraTech will have a functional enterprise-style network environment that demonstrates:

- Centralized identity management
- Secure network communication
- Remote connectivity
- User access control
-Proper infrastrucure documentation
